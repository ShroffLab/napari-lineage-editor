Napari UI for editing c elegans lineages

## Installation

```bash
pip install git+https://github.com/ShroffLab/napari_lineage_editor
```

## Development

This project uses [uv](https://docs.astral.sh/uv/) and
[just](https://just.systems). To set up a development environment:

```bash
git clone https://github.com/ShroffLab/napari_lineage_editor
cd napari_lineage_editor
just install
```

See [CONTRIBUTING.md](https://github.com/ShroffLab/napari_lineage_editor/blob/main/CONTRIBUTING.md)
for more, or run `just` to list all available recipes.
